# Helvetia — All-in-One Offline Utility App

A modular, offline-first GTK4 utility application written in C (C17).

## Building

### Prerequisites
```bash
# Debian / Ubuntu
sudo apt install build-essential meson ninja-build \
     libgtk-4-dev libglib2.0-dev

# Fedora
sudo dnf install meson ninja-build gtk4-devel glib2-devel
```

### Build & Run
```bash
meson setup build
meson compile -C build
./build/helvetia
```

> **First run note:** The app loads `src/ui/theme.css` from a relative path.
> Run from the project root, or install with `meson install -C build`.

## Project Structure
```
Helvetia/
├── meson.build                  ← top-level build
├── src/
│   ├── main.c                   ← entry point
│   ├── config.h                 ← generated by Meson
│   ├── core/
│   │   ├── plugin.h             ← HelvetiaModule interface
│   │   ├── module_registry.c/h  ← runtime module list
│   │   └── plugin_loader.c/h    ← dlopen .so plugins
│   ├── ui/
│   │   ├── window.c/h           ← GTK4 application window
│   │   └── theme.css            ← dark-mode stylesheet
│   └── modules/
│       ├── builtin.c            ← registers built-ins
│       └── utility/             ← Phase-2 utility module
│           ├── utility_module.c ← 6 tools implemented
│           └── utility_module.h
└── plugins/
    └── hello_plugin.c           ← example external plugin
```

## External Plugins

Build any `.c` file that exports `helvetia_plugin_get_module`:

```bash
gcc -shared -fPIC -o myplugin.so myplugin.c \
    $(pkg-config --cflags --libs gtk4 glib-2.0)
```

Drop the `.so` into the plugin directory (set via `PLUGIN_DIR` in `meson.build`).
